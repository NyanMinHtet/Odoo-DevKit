Key Features

  • Wizard-driven scenario setup for sales and inventory-oriented test runs
  • Inventory-aware product generation using Odoo 18 tracked goods behavior
  • Optional stock seeding in internal locations before delivery validation
  • Run history with generated orders, invoices, payments, pickings, moves, and move lines
  • Cleanup support for open generated records in safe databases

Typical Use Cases

  • Prepare realistic demo databases for pre-sales or partner enablement
  • Stress dashboards, reports, and custom KPIs with linked transactional data
  • Validate sales, accounting, and inventory customizations in non-production databases
  • Speed up manual QA by generating repeatable datasets in a few clicks

What This Module Does Not Do

This module is designed for safe non-production data generation. It is not intended to bypass Odoo licensing, hide functionality, or run destructive actions in production databases.
